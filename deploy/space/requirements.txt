# The UI's whole dependency list, and it is short on purpose.
#
# Nothing here can load a model: no scikit-learn, no XGBoost, no joblib. The
# Space could not import `src/` even if a line were added asking it to, because
# `src/` is not pushed here. Keep it that way — the moment this file grows a
# modelling dependency, the UI has stopped being a client and started being a
# second, silently different, copy of the model.
#
# pandas is named even though Streamlit installs it anyway: `app/streamlit_app.py`
# imports it directly, and a dependency you import is a dependency you declare.
# `tests/test_deploy.py` checks this list against what `app/` actually imports,
# so an import added upstairs cannot reach the Space as a crash on first load.

requests>=2.32
